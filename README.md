# Mobile Item List App

Aplikasi mobile sederhana berbasis daftar item (*scrollable list*) yang menampilkan daftar dinamis dari `Item 1` hingga `Item 13` (dan seterusnya). Disajikan dengan antarmuka pengguna (UI) yang bersih, responsif, dan ramah pengguna.

## ✨ Fitur Utama

- **Daftar Komponen Terstruktur**: Menampilkan daftar item dalam kartu (card) yang bersih dan terpisah dengan jelas.
- **Scroll Halus**: Mendukung *vertical scrolling* untuk pengalaman pengguna yang lancar.
- **Responsif**: Desain yang menyesuaikan layar berbagai perangkat mobile.

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dapat dibangun/dikembangkan menggunakan salah satu teknologi berikut:

- **Framework**: React Native / Flutter / Android Native (Kotlin/Java)

## 🚀 Cara Menjalankan Proyek (Getting Started)

### Prasyarat

Sebelum menjalankan aplikasi, pastikan Anda telah menginstal:
- [Node.js](https://nodejs.org/) (jika menggunakan React Native) / [Flutter SDK](https://flutter.dev/)
- Android Studio / VS Code
- Emulator Android atau Perangkat Fisik

### Langkah Instalasi

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/username/nama-repo.git
   cd nama-repo
   ```

2. **Instal Dependensi:**
    - Untuk React Native:
      ```bash
      npm install
      ```
    - Untuk Flutter:
      ```bash
      flutter pub get
      ```

3. **Jalankan Aplikasi:**
    - React Native:
      ```bash
      npx react-native run-android
      ```
    - Flutter:
      ```bash
      flutter run
      ```
